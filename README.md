# Train-Ticket-Reservation-System-Spring-Boot
Spring boot learning and building a Train Ticket Reservation System


Train Ticket Reservation System

Project Overview

The Train Ticket Reservation System is a backend application developed using Java and Spring Boot. It aims to simplify train searching, seat availability checking, ticket booking and reservation management.

Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

Project Architecture

The application follows a layered architecture:

- Entity Layer
- Repository Layer
- Service Layer
- Controller Layer
- Security Layer
- Configuration Layer

Current Progress

- Created the Spring Boot project.
- Designed the initial project package structure.
- Created User, Train, Passenger and Booking entity classes.
- Created repository interfaces.
- Created service classes.
- Configured the MySQL database connection.
- Prepared the security package for future authentication.

Upcoming Features
